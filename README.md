# Pizza House Simulator 🍕 — Game Guide & Hot-Keyword Site

A small SEO-friendly static guide site built for the **AI Overseas Game Hot-Keyword Site** bootcamp (出海-热词游戏站).

- **Target game:** Pizza House Simulator🍕 (Steam AppID 4132330) — co-op cooking & management sim, released 2025-08-19.
- **Goal:** capture Google search traffic for long-tail English keywords around the game (guides, recipes, co-op, automation, economy, disasters, system requirements).
- **Built with:** plain HTML + CSS, no framework. Each page targets one keyword cluster.
